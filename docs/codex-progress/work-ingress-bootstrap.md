# Work ingress bootstrap

Minimal default-branch bootstrap for the ChatGPT Work acceptance candidate ingress required by Issue #74 / PR #76.

Scope is intentionally limited to registering `.github/workflows/orchestration-work-ingress.yml` and `scripts/orchestration_work_ingress.py` on the default branch so `issue_comment` events can reach the trusted ingress before PR #76 itself is merged.
