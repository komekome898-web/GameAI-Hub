# 既知の制約

GameAI Hub の結果を利用する前に、次の範囲を確認してください。

- **掲載カタログは8サービスです。** 市場全体を網羅した一覧ではなく、未掲載サービスが条件に合う可能性があります。
- **料金の数値合計は算出できません。** 現在の料金情報は構造化された金額ではないため、結果画面は無料プランの確認状態と「金額未構造化」の件数だけを表示します。契約前に各サービスの公式料金ページで見積もってください。
- 推薦は掲載済みフィールドと中央管理された決定ルールだけで生成します。実素材の品質、ゲームへの出力対応、プラン別上限までは保証しません。
- 「不明」または「条件付き」の無料枠、商用利用、API情報は肯定材料に変換しません。結果に示す公式ソースと最終確認日を使い、採用前に手動確認してください。
- AIツールが割り当てられない工程は欠落ではありません。人が行う作業、成果物、完了条件を明示した手動工程として扱います。
