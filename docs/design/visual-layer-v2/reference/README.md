# Visual Layer v2 reference images

These files are documentation-only visual references derived from the six PNG reference images in the approved handoff package.

- `01-approved-card-material-desktop-mobile.webp` — authoritative material/look reference.
- `02-home-layout-reference.webp` — Home layout reference only.
- `03-project-layout-reference.webp` — Project layout reference only.
- `04-tools-compare-layout-reference.webp` — Tools/Compare layout reference only.
- `05-article-reading-mobile-reference.webp` — article reading layout reference only.
- `06-commercial-pricing-reference.webp` — commercial/pricing layout reference only.

The derivatives are WebP documentation copies to avoid committing the much larger PNG reference originals. They are not application assets and must not be imported from `app/`, `components/`, or CSS.

For implementation decisions, the written contract in `../handoff/docs/` takes precedence over incidental text, menu labels, prices, dates, example progress, or placeholder content visible in these mockups.
