## Interaction contract

One unbounded fractional position drives every stable, unique card node.
Dragging uses actual horizontal coordinates / measured card step. Duration never
invalidates displacement. Slow movement followed by a pause commits the nearest
card, including0.9 and2.2-card drags. Reversing before release commits the latest
position, not the farthest excursion.

Normal release may enter free inertia. Estimate velocity from actual recent80ms
samples, retaining one bounded predecessor for sparse delivery. Motion older
than100ms supplies no momentum. The contact's total age does not prohibit fresh
motion after a pause. A stationary sample anchors a restart; tiny release jitter
must not revive stale velocity. Estimate only the latest continuous direction
segment inside that window: a fresh real reversal on up must reverse momentum,
not inherit the earlier forward average. Clamp speed to10cards/s. Integrate exponential
decay analytically with tau320ms; at0.3cards/s align to the nearest integer with
the existing time-based snap. These are initial validated engineering values,
not physical Safari acceptance. No artificial one-card assistance remains.

Recontact freezes the currently displayed fractional position immediately,
discards old momentum and starts a new gesture without rounding. A new reverse
movement can coast in the opposite direction. Buttons and keyboard remain
discrete navigation; new input terminates stale release guards.

### Terminal position and release ownership

Move and up feed one timestamp-ordered position accumulator. A newer valid up
coordinate is a real final sample, including a reversal; an older terminal
sample must not overwrite a newer move. Pending up-only gestures are resolved
without capture. Established vertical/cancelled gestures never revive.
Do not globally ignore up coordinates: a fresh final reverse and a browser
reporting a fresh but incorrect coordinate are indistinguishable without more
evidence. This design rejects stale ordering, not arbitrary legitimate reversals.
The owner-reported Safari event stream remains unavailable; no exact cause claim.

A completed drag owns its trailing pointer click/focus until the next independent
pointerdown/keyboard input, bounded by a short expiry. Matching includes the
origin card/element when compatibility-click IDs differ. Keyboard activation,
next normal tap and explicit fallback focus remain usable. Focus generated by
that drag must not turn the carousel back to its origin. Do not block all focus
or every click for a blanket period.

### Interruptions

Pointercancel, actual stage capture loss, second pointer, blur/background,
width/card-step changes and unavailable/fallback modes are not releases. Stop
momentum, clear contact and guard against duplicate terminal events; return to
the last committed card without new inertia or link activation, retaining the
existing safety policy. Height-only resize with unchanged geometry preserves
motion. Active-ID publication alone is not an interruption. Page pan-y and
pinch-zoom remain available; no global touch-action:none or scroll lock.

### Circular visibility

Use a finite visible front arc and a fully invisible rear band, including for
three cards. Fade before the signed-distance wrap seam. Also hide a card for
the frame on which its signed distance wraps, so a delayed frame cannot jump
from a visible edge to the opposite visible edge. Keep one node/link per ID;
never duplicate cards, hrefs or article registrations. Counts12/30 use the same
component and motion controller through test-only component fixtures.
