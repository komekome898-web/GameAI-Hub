# モンスターコンストラクション

モンスターを育成・合体させ、勝利後のカード交換で自分だけの40枚をつくるカードバトルです。

ジャンル：カードバトル／戦略／モンスター育成・合体

[ゲームを開く](https://cadmium2525.github.io/monster_collection/)

## どんなゲーム？

作者の紹介によると、40枚のデッキで大会に挑み、モンスターの召喚・育成・技・合体を使って戦います。勝利後は相手のカードと交換し、次の大会へ向けてデッキを育てます。手持ちを更新しながら、上位大会と王座を目指します。

### 見どころ

- 試合中の育成や修行、特殊合体でモンスターを強くできます。
- 勝利後に相手のカードを選び、自分のカードと交換できます。
- カード交換で更新した40枚のデッキ構成が、次の大会につながります。大会中の能力値・スキル成長がそのまま残るという意味ではありません。

## 遊び方と操作

作者提供の開始手順：スマートフォンは横向きにし、タイトルの「TAP TO START」を選びます。初回はスターターから保存デッキを作成し、デッキを選んで大会にエントリーします。カードを選んで盤面に出し、モンスターの技を使って戦います。

作者提供の操作説明：タッチ：カードをタップし、盤面や対象のモンスターへスワイプ。技は選択後に対象をタップします。PCではマウスのクリック・ドラッグを使います。キーボードだけでの全操作は未確認です。

### 確認した環境

作者の想定：スマートフォン・タブレットの横向き用です。縦向きでは「端末を横向きにしてください」と案内されます。PCブラウザにも対応します。実機での推奨ブラウザ・必要性能の詳しい条件は未確認です。
