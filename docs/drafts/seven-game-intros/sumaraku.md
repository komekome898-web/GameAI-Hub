# ラクガキ大乱闘

自分で描いたラクガキを3Dファイターにして戦わせる、お絵かき対戦アクションです。

ジャンル：お絵かき／対戦アクション／3D

[ゲームを開く](https://cadmium2525.github.io/sumaraku/)

## どんなゲーム？

作者の紹介によると、頭・体・腕・足などを描くと、ラクガキが立体のキャラクターになります。生まれたファイターでCPUと戦ったり、オートバトルを楽しんだりできます。タイプはランダムに割り当てられ、タイプに応じて戦い方やワザが変わります。

### 見どころ

- 描いた線や塗りが立体になり、動き出します。
- キャラクターのタイプに応じて戦い方やワザが変わります。
- 自分で操作するCPU戦と、観戦できるオートバトルがあります。

## 遊び方と操作

作者提供の開始手順：タイトルの「ラクガキする」を選び、ガイドに沿って各パーツを描き、キャラ化して名前を付けます。その後「自分で戦う（CPU戦）」などを選び、使用キャラ・相手・CPUの強さを選んで開始します。初回は先に自分のキャラクターを作ります。

作者提供の操作説明：タッチ：左側のスティックと、攻撃・必殺・ジャンプ・ガードのボタン。お絵かきは指でなぞります。PC：矢印キー／WASDで移動、Jで攻撃、Kで必殺、Spaceでジャンプ、Lでガード。お絵かきはマウスでもできます。

### 確認した環境

作者の想定：スマートフォン・タブレットのタッチ操作を想定。対戦は横向きで遊ぶと操作しやすい構成です。PCブラウザにも対応します。実機での推奨ブラウザ・必要性能の詳しい条件は未確認です。

作者提供の確認記録：Windows PC／Codex内蔵ブラウザ（バージョンは未確認）／横画面1280×720、縦画面390×844相当／2026年10月11日。起動・タイトルなどの表示を確認しました。スマートフォン実機での操作と、全編クリアまでの動作は未確認です。

今回の編集作業ではゲーム操作・スマートフォン実機プレイを確認していません。
