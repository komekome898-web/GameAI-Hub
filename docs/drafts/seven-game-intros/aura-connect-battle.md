# オーラコネクト・バトル

同じ色のオーラをつないで消し、仲間とダンジョンを攻略するパズルRPGです。

ジャンル：パズルRPG／キャラクター育成／チーム編成

[ゲームを開く](https://cadmium2525.github.io/aurapuzzle_-adventure/)

ゲーム内容・操作・制作情報は作者提供の紹介をもとに編集しています。確認記録は初期画面の表示が中心で、スマートフォン実機の操作と全編プレイは未確認です。

## どんなゲーム？

オーラをつないで攻撃や回復を行い、敵とのバトルを進めます。仲間を編成・強化・進化させ、サポートキャラクターと一緒にダンジョンへ出撃します。盤面のつなぎ方と、チームの組み合わせを考える楽しさがあります。

### 見どころ

- 同じ色のオーラを4つ以上つないで消すパズルです。
- 3人の仲間と1人のサポートでチームを組みます。
- 強化・進化・開眼など、仲間を育てる要素があります。

## 遊び方と操作

1. 読み込み後の「TAP TO START」を選びます。ホームからダンジョンを開き、ステージ・チーム・サポートを選び、編成を確認して「突入」で開始します。初期の案内に沿って編成を整えると進めやすくなります。

タッチでオーラをなぞってつなぎ、メニューやスキルをタップします。PCではマウスのドラッグとクリックを使います。キーボードだけで一通り遊べるかは未確認です。
