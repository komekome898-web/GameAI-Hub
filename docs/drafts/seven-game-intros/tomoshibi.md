# 灯のルミナ

少女ルミナを守り、灯りを頼りに暗い地下聖堂を進む謎解きアクションです。

ジャンル：謎解きアクション／横スクロール／冒険

[ゲームを開く](https://cadmium2525.github.io/tomoshibi/)

## どんなゲーム？

作者の紹介によると、老紳士グレイを操作して、少女ルミナとともにダンジョンを進みます。灯竿で影を退けながら、ルミナを呼ぶ・待たせる・助ける行動を使い、扉や足場の仕掛けを解きます。自分だけで先へ進むのではなく、二人で無事に進むことが攻略の鍵です。

### 見どころ

- 少女を守りながら進む、同行者のいるアクションです。
- ルミナと押し石、石板、レバーなどを組み合わせて仕掛けを解きます。
- ドット絵風の世界と、暗闇に灯る光の雰囲気を楽しめます。

## 遊び方と操作

作者提供の開始手順：タイトル画面でZ／Enterを押します。タッチ端末では画面をタップして開始します。プロローグを見た後、グレイとルミナで地下聖堂を進みます。操作説明はポーズ画面でも確認できます。

作者提供の操作説明：タッチ：スティックで移動、ジャンプ・灯竿・呼ぶのボタンを使用。PC：左右キーで移動、Z／Spaceでジャンプ、Xで灯竿、Cで「待て／おいで」、下キー長押しで手を差し伸べる、上キーでレバー、Enter／Escでポーズ。ゲームパッドにも対応する設計です。

### 確認した環境

作者の想定：スマートフォン・タブレットは横向きを推奨。縦向きでは上側にゲーム、下側にコントローラーを置く構成です。PCブラウザにも対応します。実機での推奨ブラウザ・必要性能の詳しい条件は未確認です。
