# クリエイトモンスターズ

集めて、育てて、どこまでも行ける。

ジャンル：ロールプレイング

[ゲームを開く](https://crimon.pages.dev/)

ゲーム内容・操作・制作情報は作者提供の紹介をもとに編集しています。確認記録は初期画面の表示が中心で、スマートフォン実機の操作と全編プレイは未確認です。

## どんなゲーム？

モンスターを集めて育てる育成RPGです。装備やスキルを組み合わせ、自分だけのパーティを編成します。ダンジョンやアリーナに加え、自動周回の機能もあります。

### 見どころ

- スキルの豊富さ
- クリエイトによる幅広い育成
- 自動周回可能

## 遊び方と操作

1. タイトルの「Tap to Start」を選びます。登録せずにホームへ進めます。
2. ホームの「遊び方」で基本の案内を確認します。
3. 「冒険」からダンジョンへ進みます。
