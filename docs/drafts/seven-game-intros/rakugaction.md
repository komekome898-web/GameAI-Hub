# ラクガキアクション

描いたラクガキが立体になって、5つのステージを冒険する3Dアクションです。

ジャンル：お絵かき／3Dアクション／探索／タイムアタック

[ゲームを開く](https://cadmium2525.github.io/rakugaction/)

## どんなゲーム？

作者の紹介によると、自分で描いたキャラクターで、星を集めながらステージを攻略します。体の形によって能力やアクションが変わるので、見た目をつくることと攻略がつながっています。全5ステージを通して走るタイムアタックもあります。

### 見どころ

- 人型だけでなく、四足・多腕・翼のあるキャラクターなども描けます。
- 描いたパーツや体型から、能力・動き・コンボが変わります。
- 星集めとステージ探索に加え、タイムアタックで記録を追求できます。

## 遊び方と操作

作者提供の開始手順：起動時にデモが流れている場合は、画面をタップしてタイトルに戻ります。「ラクガキを描く」でパーツを描き、3Dプレビューを確認してキャラクターを保存します。「はじめる」または「ステージであそぶ」からステージを選んで開始します。

作者提供の操作説明：タッチ：左側の仮想スティックで移動、右下のJUMP・ACTIONでジャンプや攻撃、画面右側のスワイプでカメラ操作。PC：WASD／矢印で移動、Space／Zでジャンプ、X／J／Shiftでアクション、Esc／Pで一時停止。お絵かきはタッチまたはマウス。

### 確認した環境

作者の想定：スマートフォンは横向き。iPhone Safari・Android Chromeを優先した設計で、PCブラウザにも対応します。実機でのタッチ感や端末別の性能は未確認です。

作者提供の確認記録：Windows PC／Codex内蔵ブラウザ（バージョンは未確認）／横画面1280×720、縦画面390×844相当／2026年10月11日。起動・タイトルなどの表示を確認しました。スマートフォン実機での操作と、全編クリアまでの動作は未確認です。

今回の編集作業ではゲーム操作・スマートフォン実機プレイを確認していません。
