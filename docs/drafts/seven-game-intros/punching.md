# ぶっ飛ばせ！ムカつくアイツ！

5回のミニゲームでパンチ力をためて、キャラクターを宇宙の向こうまでぶっ飛ばす爽快ゲームです。

ジャンル：ハイパーカジュアル／ミニゲーム／スコアアタック

[ゲームを開く](https://cadmium2525.github.io/punching/)

## どんなゲーム？

作者の紹介によると、毎回選ばれる5つのミニゲームで、タイミングや連打の精度を競います。ためた力でフィニッシュパンチを放ち、飛距離を伸ばします。短いプレイの中で、上手く決まったときの派手な演出と記録更新を楽しめます。

### 見どころ

- 10種類のミニゲームから、毎回5種類が選ばれます。
- タイミングの精度によってパンチ力と飛距離が変わります。
- 全PERFECTでGOD PUNCHを狙えます。

## 遊び方と操作

作者提供の開始手順：タイトルの「ゲームスタート」を選ぶと、5回のミニゲームが始まります。相手を変える場合は先に「キャラクター選択」を開きます。各ミニゲームの案内に合わせて操作し、最後のパンチと飛行結果へ進みます。

作者提供の操作説明：タッチまたはマウスで、タイミングよく押す・連打する・指定位置を狙うなどの操作をします。一部の入力はSpace／Enterにも対応しますが、位置を狙う操作にはタッチまたはマウスを使います。

### 確認した環境

作者の想定：スマートフォンの縦向きが基本です。PCでも縦長のゲーム画面をマウスで操作できます。実機での推奨ブラウザ・必要性能の詳しい条件は未確認です。

作者提供の確認記録：Windows PC／Codex内蔵ブラウザ（バージョンは未確認）／横画面1280×720、縦画面390×844相当／2026年10月11日。起動・タイトルなどの表示を確認しました。スマートフォン実機での操作と、全編クリアまでの動作は未確認です。

今回の編集作業ではゲーム操作・スマートフォン実機プレイを確認していません。
