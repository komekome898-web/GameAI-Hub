## モンヒロ画像のマスク許可

どっさん：「モンヒロの画像左下に PLAYER ID が写っているので、掲載用だけそこを隠していい？元画像はそのまま残すね。」

本人：「隠しといて」

親から、原画像を保持し、掲載用派生画像だけ左下のPLAYER ID表示を不透明にマスクし、縮小・圧縮後も文字が読めないことを画像で確認する指示を受領。他のゲーム画面部分やロゴを不必要に変更しない。

この実行環境では原画像の正規取得に失敗しているため、マスクは未実行。許可の再確認は不要。正規原本取得後、指示された局所マスクと通常の掲載用圧縮・リサイズのみ実施する。元画像にPLAYER IDが写るため、未加工原本を公開配信ディレクトリや公開リポジトリへ入れない。
