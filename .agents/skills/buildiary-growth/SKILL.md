# ビルダイアリー成長分析

このSkillはCodexの作業手順と道具を追加する。重みの学習や自律公開を行う機能ではない。
初回利用時はこのSkillの使用を伝える。ユーザーが報告前の評価を指定している場合、その評価・報告経路を優先する。

## 準備

ルートAGENTS.md、CODEX_CLOUD_TASK.md、docs/GROWTH_STRATEGY.mdを読む。現在のユーザー目標を優先し、広告・収益へ勝手に置き換えない。Git bootstrap後に専用branchへ進む。実装は一つのまとまりとし、重要な判断と成果物は独立レビューを受ける。

次の資料と道具を使う。

- [専門資料](references/methods.md)：何を調べ、どの条件で何を判断できるか。
- [診断の完成例・失敗例](references/cases.md)：原値→対立仮説→追加調査→変更の選択。
- [実行方法](../../../docs/growth/README.md)：入力形式、コマンド、公開範囲。
- `python scripts/growth/analyze.py /owner-only/observations.json --brief /owner-only/brief.json --output /owner-only/diagnostics.json`
- `python -m unittest discover -s tests/growth -v`

## 毎回の実行

1. 目標、対象読者、実行可能な負担、前回の変更SHAを確定。既存資料・既存認証で取得し、新規認証や課金はしない。
2. GA/GSCの各観測に出典、取得日時、開始終了日、timezoneの確認状態、dimension、scope、欠測と計測変更を残す。非公開の原値・会話・診断結果はrepo外のowner-only領域へ保存し、public commit/PR/CI artifactへ載せない。公開可能なコードと合成fixtureだけを分離する。
3. 候補に今回のtarget_periodを指定し、診断コードを実行。原表との合計照合、nullと0、page/query coverage、履歴PV、検証流入を確認。指標が別母集団なら割らない。集計値同士を結合して検索語×ページの実観測に見せない。
4. 実際のpage×queryが取れた組から検索結果、競合本文、自サイト本文、読者の未完タスクを照合。検索ツールの結果は時刻・言語・地域・device・取得方法を残し、取得不能な条件を明記。公開検索の現在値を過去28日の順位と同一視しない。一次資料へ進み、料金/仕様は公式で検証する。
5. 検索記事改善、既存記事への入口、需要のある新記事、外部チャネル、技術的阻害を比較。未完タスクの解消と流入増の仕組みを説明し、最優先の獲得実験と、既存入口の小改善を分けて選ぶ。現GSCの表示数を市場上限にせず、新しい読者の問い・自前の実作品・既存内容との差分・配布経路の四つも調べる。根拠のないICEやPV予測を作らない。データ不足だけを理由に全作業を止めず、直接確認した読者課題から具体案まで進める。
6. `brief`にURL、変更本文または適用確認できるpatch、読者価値、工数見積りの内訳、期待の成立条件、見送った案、観測計画、推薦を変える条件、証拠IDを揃える。配布施策のbriefには、対象読者の状況と答える疑問、入口で約束する利益、採用する表現形式と実際の見本、到達先でその約束を満たす箇所を示す。同じ素材の短文・完成物画像・実操作の短い実演・修正前後比較を対案として検討し、原資料の該当箇所から、何を伝えられるか・何を伝えられないか・制作負担を比較して選ぶ。未選択の形式にも理由を残す。全形式の制作を要件にしない。コードのcontract passは意味的採用の判定ではない。独立レビューが原資料と実差分を照合し、役割別の保持本文・SHA256と別担当の照合記録を残す。ラベルの条件分岐テストを本文診断能力の証明にせず、P0/P1/重大P2を修正する。
7. 権限内でコード・テスト・資料を作る。サイト施策はreview用差分まで。merge、公開、本番設定、外部投稿は別の明示的指示があるときだけ行う。
8. 採用後は公開SHA・日時・変更内容と観測を対応させる。PVと読者proxyを別表示し、検証流入を分離して同曜日を含む完了期間で追う。少標本なら「成功/失敗」の二択へ急がず、到達・操作・有用性の直接確認を追加して次の変更を決める。

## 次回へ残すもの

コードで再現する集計、私的証拠の所在、選択根拠、実行案、検証結果、未完の取得対象、次の具体操作。新しい専門的な学びは適用条件・反例とともに参照資料へ戻す。非公開の結果は公開Skillへ混ぜない。
